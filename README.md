# Taxi Syd

Swedish website preview for airport taxi trips from Lund and Malmö to Kastrup and Malmö Airport.

Run the site locally with Node.js:

```sh
node --watch server.mjs
```

Open [http://127.0.0.1:4173/](http://127.0.0.1:4173/). The booking form previews the trip in the browser. The contact page and provisional pickup areas need business details before the site goes live.
